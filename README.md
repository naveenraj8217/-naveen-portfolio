# Naveen Raj A - Portfolio

Static site (no build). Premiere Pro style editor theme.

## Deploy
1. Upload all files in this folder to your GitHub repo (replace old files).
2. Netlify redeploys automatically (publish directory ".").

## Google Search Console
Add your verification tag inside <head> of index.html, then submit https://naveenrajeditor.netlify.app/sitemap.xml
