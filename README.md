# Naveen Raj A - Portfolio (with admin)

1. Edit admin/config.yml: set repo: YOUR_GITHUB_USERNAME/YOUR_REPO_NAME and branch.
2. Upload everything to GitHub; Netlify redeploys.
3. Enable GitHub login in Netlify (Site configuration > Access & security > OAuth).
4. Open https://naveenrajeditor.netlify.app/admin, log in, add content, Publish.
